# B2B 견적서 자동화 에이전트 (MVP)

인쇄/포장재 업종 대상, 이메일·카톡 문의 원문(자유 형식)을 입력받아
1) 품목/수량/스펙을 파싱하고
2) 하드코딩된 단가표(수량 할인 포함)로 견적을 계산하고
3) reportlab로 견적서 PDF를 자동 생성하는 실동작 MVP입니다.

FastAPI 백엔드 + 최소 HTML 폼으로 구성되어 있으며, curl로도 바로 PDF를 뽑을 수 있습니다.

## 아키텍처

```
app/
  data/price_table.json   # 품목별 단가/최소수량/수량할인표 (하드코딩 예시)
  parser.py                # 자유 텍스트 -> 품목/수량/스펙 라인아이템 파싱
  pricing.py                # 라인아이템 -> 단가표 매칭, 할인 적용, 합계 계산
  pdf_generator.py          # reportlab로 견적서 PDF 렌더링 (한글 폰트 자동 등록)
  main.py                   # FastAPI 라우트 (웹폼 + API)
  templates/                # index.html(입력폼), result.html(결과 화면)
output/                     # 생성된 PDF가 저장되는 곳 (실행 시 자동 생성)
samples/                    # 데모 검증용으로 남겨둔 실제 생성 PDF 샘플
```

## 실행 방법

```bash
cd ~/dev/quote-automation-agent

# 1) 가상환경 생성 및 의존성 설치 (최초 1회)
python3 -m venv venv
./venv/bin/pip install -r requirements.txt

# 2) 서버 실행
./venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

서버가 뜨면 브라우저에서 `http://127.0.0.1:8000` 접속 → 문의 텍스트 붙여넣고
"견적서 PDF 생성" 클릭하면 파싱 결과 + PDF 다운로드 링크가 표시됩니다.

## 지원 품목 (예시 단가표, `app/data/price_table.json`)

| 품목 | 단위 | 기본단가 | 최소수량 | 수량 할인 |
|---|---|---|---|---|
| 명함 | 매 | 50원 | 100매 | 500매↑ 10%, 1000매↑ 18%, 3000매↑ 25% |
| 전단지 | 매 | 35원 | 100매 | 1000매↑ 12%, 5000매↑ 22%, 10000매↑ 30% |
| 스티커 | 매 | 80원 | 100매 | 500매↑ 8%, 2000매↑ 18%, 5000매↑ 28% |
| 포장박스 | 개 | 900원 | 50개 | 300개↑ 10%, 1000개↑ 20%, 3000개↑ 28% |
| 쇼핑백 | 개 | 650원 | 100개 | 500개↑ 10%, 2000개↑ 20%, 5000개↑ 27% |
| 봉투 | 매 | 120원 | 100매 | 1000매↑ 12%, 3000매↑ 20% |
| 브로슈어 | 부 | 1,200원 | 50부 | 300부↑ 10%, 1000부↑ 20% |
| 포장테이프 | 롤 | 1,800원 | 50롤 | 200롤↑ 8%, 500롤↑ 15% |

품목명은 "명함", "business card" 등 여러 별칭(aliases)으로도 인식됩니다.
파서가 품목/수량을 못 찾으면 견적에서 제외하지 않고, PDF 하단 "확인 필요 항목"에
원문 그대로 표시해 사람이 수동으로 검토할 수 있게 합니다. VAT 10%는 자동 가산됩니다.

## API 엔드포인트

- `GET /` — 입력 폼 + 현재 단가표 웹 UI
- `POST /api/parse` — 텍스트만 파싱해서 JSON으로 미리보기 (PDF 생성 없음)
- `POST /generate-quote` — 문의 텍스트 → PDF를 바로 응답(파일) — curl용
- `POST /generate-quote-form` — 문의 텍스트 → 결과 HTML 페이지(다운로드 링크 포함) — 웹폼용
- `GET /download/{filename}` — 생성된 PDF 다운로드
- `GET /api/price-table` — 현재 단가표 JSON
- `GET /health` — 헬스체크

## 데모 시나리오 (실제 검증 완료)

### 시나리오 1 — curl로 직접 PDF 받기

입력 (`inquiry_text`):
```
안녕하세요, 견적 부탁드립니다.
- 명함 1000장 (350g 아트지, 양면)
- 전단지 5000매 A4 컬러
- 포장박스 300개 (표준 사이즈)
- 특수 마그넷 500개 (자석 재질)
감사합니다.
```

호출:
```bash
curl -s -X POST http://127.0.0.1:8000/generate-quote \
  -F "customer_name=주식회사 데모컴퍼니" \
  --form-string "inquiry_text=안녕하세요, 견적 부탁드립니다.
- 명함 1000장 (350g 아트지, 양면)
- 전단지 5000매 A4 컬러
- 포장박스 300개 (표준 사이즈)
- 특수 마그넷 500개 (자석 재질)
감사합니다." \
  -o samples/sample_quote_output.pdf
```

결과 (PDF 내용, 파싱/계산 자동 처리):
- 명함 1,000매 × 50원 → 1000매 이상 할인 18% 적용 → 단가 41원 → **41,000원**
- 전단지 5,000매 × 35원 → 5000매 이상 할인 22% 적용 → 단가 27.3원 → **136,500원**
- 포장박스 300개 × 900원 → 300개 이상 할인 10% 적용 → 단가 810원 → **243,000원**
- "특수 마그넷 500개"는 단가표에 없는 품목 → **"확인 필요 항목"**으로 PDF 하단에 자동 표기 (견적 누락 대신 사람이 확인하도록 처리)
- 공급가액: 420,500원 / 부가세(10%): 42,050원 / **합계: 462,550원**

생성된 파일: `samples/sample_quote_output.pdf`

### 시나리오 2 — 웹 폼(POST /generate-quote-form)으로 생성

입력: `쇼핑백 2000개 크라프트지로 부탁드립니다. 봉투도 3000매 필요합니다.`

- 쇼핑백 2,000개 × 650원 → 2000개 이상 할인 20% → 단가 520원 → 1,040,000원
- 봉투 3,000매 × 120원 → 3000매 이상 할인 20% → 단가 96원 → 288,000원
- 공급가액 1,328,000원 + VAT 132,800원 = **합계 1,460,800원**

생성된 파일: `samples/sample_quote_form_output.pdf`

두 PDF 모두 로컬에서 서버를 띄운 상태로 실제 curl 요청을 보내 생성/검증했습니다
(`pypdf`로 텍스트 추출해 한글 렌더링과 계산 결과를 직접 확인함).

## 한계 및 다음 단계 (MVP 이후)

- 파서는 정규식 + 별칭 매칭 기반의 규칙 기반 파서입니다. 복잡한 자연어(가격 협상, 다중 옵션 조합)는
  LLM 기반 파서로 교체하면 인식률을 높일 수 있습니다.
- 단가표는 JSON 하드코딩입니다. 실제 운영시 DB/스프레드시트 연동으로 교체 필요.
- 이메일/카톡 자동 수집(웹훅) 연동은 범위 밖이며, 현재는 텍스트를 직접 붙여넣는 구조입니다.
- 다중 옵션(지질, 후가공 등)별 단가 세분화는 현재 반영되어 있지 않고 spec_note로만 기록됩니다.
